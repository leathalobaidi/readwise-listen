# Security 🔐

## Protect your Readwise token

Never paste a real Readwise token into a bug report, screenshot, test, commit or pull request.

Readwise Listen keeps the submitted token only in the open player tab's memory. Closing the tab or pressing **Disconnect** erases it. The application does not intentionally save the token in browser storage or log it.

## Reporting a problem

If you find a security problem, open a GitHub issue containing only the steps needed to reproduce it. Replace every credential with a clearly fake value. Revoke any real token that was accidentally exposed before sharing the report.
