# Install Readwise Listen

## Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select the **Readwise Listen Chrome Extension** folder.
5. Pin **Readwise Listen** from the Extensions menu if you want its button always visible.

## Brave

Use the same steps at `brave://extensions`.

If an older copy is already loaded, click its **Reload** button after replacing the extension folder.

The token is erased from the field immediately after submission, kept only in the open player's memory, and sent only to Readwise over HTTPS. Closing the player tab or pressing **Disconnect** erases it, so you will paste it again next time.
